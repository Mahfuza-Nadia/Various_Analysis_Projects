# Exchange Rate Depreciation and Inflation in Bangladesh
### Interactive Power BI Dashboard | July 2006 – June 2026

## Project Overview

This project presents an interactive Power BI dashboard exploring inflation and exchange-rate movements in Bangladesh using monthly macroeconomic data from July 2006 to June 2026.

The dashboard visualizes macroeconomic trends and examines the relationship between exchange-rate depreciation and inflation. It was developed using Microsoft Power BI, with data prepared and analyzed in R.

## Dashboard Features

The dashboard includes the following visualizations:

- **Key Performance Indicators:** Average inflation, average exchange rate, average depreciation and maximum inflation.
- **Inflation Trend:** Monthly inflation movements in Bangladesh.
- **Exchange Rate Trend:** Changes in the official exchange rate (BDT per USD).
- **Scatter Plot:** The observed relationship between exchange-rate changes and inflation.
- **Date Filter:** An interactive date slicer for exploring different periods.

## Data

The dashboard uses monthly macroeconomic data for Bangladesh covering July 2006 to June 2026.

The main variables include:

| Variable | Description |
|---|---|
| CPI | Consumer Price Index |
| Inflation | Year-on-year CPI inflation (%) |
| Exchange_Rate | Official exchange rate (BDT per USD) |
| Exports | Merchandise exports |
| Imports | Merchandise imports |
| Exchange_Rate_Change | Monthly percentage change in the exchange rate |
| Trade_Balance | Exports minus imports |
| Export_Growth | Percentage change in exports |
| Import_Growth | Percentage change in imports |

## Methodology

The original data were cleaned and transformed using R. The prepared monthly dataset was imported into Power BI for visualization.

The dashboard uses KPI cards, line charts, a scatter plot and an interactive date slicer to explore macroeconomic trends and relationships.

## Key Observations

The visualizations allow users to explore changes in inflation and the exchange rate over time and examine their observed relationship.

The scatter plot provides a visual representation of the association between exchange-rate changes and inflation. These visual relationships are descriptive and do not establish causality.

## Tools Used

- Microsoft Power BI — Dashboard development and data visualization
- To interact with the report, download the PBIX file and open it using Microsoft Power BI Desktop. 

## Purpose

This project demonstrates the application of data visualization techniques to an applied economics topic. It showcases the use of Power BI to communicate macroeconomic trends and explore relationships using monthly economic data.
