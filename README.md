# Data Analysis Projects

This repository contains three data analysis projects demonstrating SQL, Python, R programming and Excel skills.

### 1. COVID-19 Dataset Exploration

Contains a **BigQuery SQL script** used to explore and analyze a COVID-19 dataset. The analysis includes data exploration, and key metrics related to COVID-19 cases and deaths.

### 2. Bangladesh Protein Supply Trend Analysis

Contains a **PDF report, Excel analysis file, and Python code** examining protein supply trends in Bangladesh from 2010–2023. The analysis groups protein sources into six major food groups: Fish, Meat, Milk, Eggs, Pulses, and Cereals and examines changes in protein supply, contribution shares, and the distribution between animal-source and plant-source foods.
# Exchange Rate Depreciation and Inflation in Bangladesh

### 3. Exchange-rate movements and inflation in Bangladesh

This project contains a **PDF report, Excel analysis files, and code** examining the relationship between exchange-rate movements and inflation in Bangladesh using monthly economic data from the World Bank Global Economic Monitor (GEM). The analysis covers the period from July 2006 to June 2026.

The main research question is whether exchange-rate depreciation is associated with higher inflation in Bangladesh. The study also examines whether exchange-rate changes are associated with inflation with a one- or two-month lag.

The analysis was conducted in R and includes data cleaning, descriptive analysis, visualizations, correlation analysis, linear regression, lagged regression models, diagnostic tests, and Newey-West standard errors. The results are interpreted as statistical associations and do not establish causality.
